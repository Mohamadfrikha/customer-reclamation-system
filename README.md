# Plateforme de Gestion des Réclamations et Interventions Techniques

## Description
Conception et développement d’une application web de gestion des réclamations clients et des interventions techniques.

## Fonctionnalités principales
- Gestion des réclamations clients.
- Facturation automatique selon le statut de garantie de l’article : gratuite si l’article est sous garantie, payante sinon.
- Génération de factures au format PDF.
- Envoi automatique des factures par e-mail au client.

## Technologies
- **Backend :** ASP.NET
- **Frontend :** ReactJS
- **UI :** DaisyUI
